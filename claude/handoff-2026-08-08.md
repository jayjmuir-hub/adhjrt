## ⚠️ The four traps that cost the most, all now in `claude/lessons.md`

1. **Writing *about* the skip-ci marker in a commit message triggers it.**
   Netlify reads the whole message, not the subject. A merge to `main` silently
   did nothing and was misdiagnosed as a dead webhook.
2. **The bold-span loss check reads a fraction of what it claims to.** It
   passed a deletion that broke the suite. Use the line-level version.
3. **A 404 proves nothing without an unruled sibling returning 200** in the
   same deploy — an absent file 404s identically.
4. **The stop hook's "unpushed" alarm has TWO causes** and they look identical:
   a scratch branch name, and a stale tracking ref. Fixing one and declaring
   victory was wrong, within the hour.

⚠️ **The thread joining all four: the verification needed verifying.** Every one
was a check that reported success while measuring the wrong thing.

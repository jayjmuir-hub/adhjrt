# claude/plans/ — removed

This folder held step-by-step build plans for features that have since been
built. Once the code existed, a plan was only ever a second, staler
description of it, and sessions kept following plans whose steps the code had
already overtaken. The documentation cut
(`claude/decisions/2026-09-10-documentation-cut.md`) deleted them.

What the code does is in `RESTORE.md`. Why it was built that way is in
`claude/decisions/`. The plans themselves are in git history before the cut
commit. **Do not recreate this folder**: a plan lives in the pull request or
the Linear ticket for the work, and dies with it.
